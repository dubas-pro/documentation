# Wie erstellt man eine ZuGFeRD-E-Rechnung mit dem Sales Pack in EspoCRM?

1. Öffnen Sie **Rechnungen** oder **Gutschriften**.
2. Erstellen Sie einen neuen Datensatz oder verwenden Sie einen vorhandenen.
3. Öffnen Sie das Dropdown-Menü:

![ZuGFeRD e-invoice](../images/zugferd/dropdown-zugferd.png)

Wählen Sie im Popup das passende Format aus.

![ZuGFeRD e-invoice format](../images/zugferd/format-zugferd.png)

Sie können die Struktur überprüfen, indem Sie auf die Schaltfläche **Validieren** klicken.

![ZuGFeRD e-invoice validate](../images/zugferd/validate-zugferd.png)

Um das PDF zu exportieren, klicken Sie auf die Schaltfläche **Exportieren**.

Das war's. Wie Sie unten sehen können, wurde das erzeugte PDF auch von einem externen Prüftool erfolgreich validiert.


![ZuGFeRD e-invoice validation](../images/zugferd/success-zugferd.png)
