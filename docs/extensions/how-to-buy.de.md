# Wie kauft man unsere Erweiterungen?
1. Besuchen Sie unseren [Marktplatz](https://devcrm.it/marketplace/).
2. Wählen Sie die Erweiterungen aus, die Sie kaufen möchten.
3. Legen Sie jede Erweiterung in den Warenkorb.
4. Gehen Sie zur Kasse und füllen Sie alle erforderlichen Felder aus.
5. Wählen Sie die Zahlungsmethode und bezahlen Sie Ihre Bestellung.

Sie können uns auch per E-Mail kontaktieren: [contact@dubas.pro](mailto:contact@dubas.pro).
