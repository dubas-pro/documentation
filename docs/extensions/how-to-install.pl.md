# Jak zainstalować rozszerzenie w EspoCRM

1. Zaloguj się na konto użytkownika z uprawnieniami administratora.
2. Przejdź do **Administracja > Rozszerzenia**.
3. Kliknij przycisk **Wybierz plik**.
4. Wybierz z komputera pakiet rozszerzenia.
5. Potwierdź instalację rozszerzenia.
6. Poczekaj na zakończenie procesu instalacji.
7. Po zakończeniu instalacji pojawi się odpowiednie powiadomienie.
