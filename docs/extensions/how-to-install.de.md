# So installieren Sie eine Erweiterung in EspoCRM

1. Melden Sie sich als Benutzer mit Administratorrechten an.
2. Gehen Sie zu **Administration > Erweiterungen**.
3. Klicken Sie auf die Schaltfläche **Datei auswählen**.
4. Wählen Sie das Erweiterungspaket von Ihrem Computer aus.
5. Bestätigen Sie die Installation der Erweiterung.
6. Warten Sie, bis der Installationsvorgang abgeschlossen ist.
7. Sie erhalten eine Benachrichtigung, dass die Installation abgeschlossen ist.
