# Jak kupić nasze rozszerzenia?
1. Przejdź do naszego [marketplace](https://devcrm.it/marketplace/).
2. Wybierz rozszerzenia, które chcesz kupić.
3. Dodaj każde rozszerzenie do koszyka.
4. Przejdź do kasy i wypełnij wszystkie wymagane pola.
5. Wybierz metodę płatności i opłać zamówienie.

Alternatywnie można po prostu skontaktować się z nami za pomocą poczty elektronicznej pod adresem [kontakt@dubas.pro](mailto:kontakt@dubas.pro).
