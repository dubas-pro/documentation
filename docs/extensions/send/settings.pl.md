# Ustawienia Rozszerzenia (Send Settings)

Dostęp do konfiguracji modułu znajduje się w sekcji:
**Administration » Send Settings**.

!!! example "Przejdź do ustawień"
    [#Admin/dubasSend](https://dubas.pro/redirect/#Admin/dubasSend)

---

## Opcje konfiguracji globalnej

### General Settings
* **Theme:** Wybór motywu graficznego dla stron publicznych udostępnień.
* **Anonymize IP Address:** Gdy zaznaczone, adresy IP odbiorców otwierających linki nie będą zapisywane w dziennikach zdarzeń.

### Files Page Configuration
* **Hide sender and share date:** Ukrywa w nagłówku strony informację o osobie udostępniającej (np. *Admin*) oraz dacie utworzenia linku.
* **Ukryj informację, dla kogo są pliki (`dubasSendAudienceInfoDisabled`):** Ukrywa etykietę informującą o docelowej grupie odbiorców (np. *Przeznaczone dla: Wszyscy zalogowani użytkownicy*) na stronach odmowy dostępu.
* **File page intro text:** Wielojęzyczny tekst wprowadzający wyświetlany w górnej części strony udostępnienia. Wspiera formatowanie **Markdown**.
* **File page footer text:** Wielojęzyczny tekst stopki wyświetlany na dole strony udostępnienia. Wspiera formatowanie **Markdown**.

!!! tip "Obsługa Wielojęzyczności w Ustawieniach"
    Możesz zdefiniować różne wersje tekstów nagłówka i stopki dla poszczególnych języków, korzystając z przycisku **+ Add language**.
